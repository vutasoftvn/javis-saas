from enum import StrEnum


class Intent(StrEnum):
    GENERAL_CHAT = "GENERAL_CHAT"
    PROJECT_QUERY = "PROJECT_QUERY"
    PROJECT_ANALYSIS = "PROJECT_ANALYSIS"
    SALES = "SALES"
    MARKETING = "MARKETING"
    FINANCE = "FINANCE"
    LEGAL = "LEGAL"
    RESEARCH = "RESEARCH"
    DEVELOPER = "DEVELOPER"
    UNKNOWN = "UNKNOWN"


GREETING_MESSAGES = {
    "chào",
    "xin chào",
    "hello",
    "hi",
    "hey",
    "chào cosa",
}


def deterministic_intent(message: str) -> Intent | None:
    normalized = message.strip().lower()

    if normalized in GREETING_MESSAGES:
        return Intent.GENERAL_CHAT

    return None

# 12. ADK Graph mẫu

ADK 2.0 cho phép agent/function/tool trở thành node và routing thông qua graph; Python API hiện cung cấp `Agent`, `Workflow` và `Event`. ([adk.dev][3])

Ví dụ tham khảo:

```python
from google.adk import Agent, Workflow, Event


intent_agent = Agent(
    name="intent_classifier",
    model="gemini-flash-latest",
    instruction="""
    Classify the message into:
    PROJECT_QUERY, SALES, FINANCE, MARKETING, GENERAL_CHAT.
    Return one category only.
    """,
    output_schema=str,
)


def intent_router(intent: str):
    return Event(route=[intent.strip()])


def general_handler():
    return Event(
        message="Xin chào! Tôi là COSA. Tôi có thể hỗ trợ bạn điều gì?"
    )


def project_handler():
    return Event(route=["PROJECT_WORKFLOW"])


def sales_handler():
    return Event(route=["SALES_WORKFLOW"])


root_agent = Workflow(
    name="cosa_root_router",
    edges=[
        ("START", intent_agent, intent_router),

        (
            intent_router,
            {
                "GENERAL_CHAT": general_handler,
                "PROJECT_QUERY": project_handler,
                "SALES": sales_handler,
            },
        ),
    ],
)
```

Đây là code khởi đầu.

Claude Code phải kiểm tra API cụ thể của phiên bản `google-adk` được lock trước khi production hóa.

# 20. Gateway implementation mẫu

```python
class AgentGateway:

    def __init__(
        self,
        registry,
        permission_service,
        approval_service,
        audit_service,
    ):
        self.registry = registry
        self.permission_service = permission_service
        self.approval_service = approval_service
        self.audit_service = audit_service

    async def execute(
        self,
        *,
        context,
        tool: str,
        args: dict,
    ):
        definition = await self.registry.get_tool(tool)

        await self.permission_service.require(
            agent_id=context.agent_id,
            tool=tool,
        )

        if definition.requires_approval:
            await self.approval_service.require_approval(
                context=context,
                tool=tool,
                args=args,
            )

        await self.audit_service.log_start(
            context=context,
            tool=tool,
            args=args,
        )

        try:
            result = await definition.handler(**args)

            await self.audit_service.log_success(
                context=context,
                tool=tool,
            )

            return result

        except Exception as exc:
            await self.audit_service.log_failure(
                context=context,
                tool=tool,
                error=str(exc),
            )

            raise
```

# 68. InteractionService

```python
class InteractionService:

    async def handle(
        self,
        *,
        message,
        context,
    ):

        intent = deterministic_intent(message)

        if intent is None:
            intent = await self.intent_classifier.classify(
                message,
                context=context,
            )

        route = await self.router.resolve(intent)

        return await route.execute(
            message=message,
            context=context,
        )
```

# 101. Quy tắc cho mọi phát triển COSA từ thời điểm áp dụng tài liệu này

Mọi chức năng agent mới phải trả lời được 10 câu:

```text
1. Intent nào kích hoạt?

2. Agent nào chịu trách nhiệm?

3. Agent được đọc dữ liệu nào?

4. Agent được dùng tool nào?

5. Model profile nào?

6. Workflow deterministic hay agentic?

7. Side effect ở đâu?

8. Approval ở đâu?

9. Eval case nào chứng minh nó đúng?

10. Trace ở đâu để debug?
```

Nếu chưa trả lời được 10 câu này:

**chưa được triển khai production.**

Một thay đổi tôi đánh giá đặc biệt quan trọng là **không bắt đầu bằng việc “tích hợp ADK vào tất cả agent”**. Nên giao Claude Code chạy **Master Prompt → Phase 0 Audit → Router → Registry/Gateway**, rồi mới đưa ADK vào một workflow mẫu. Như vậy ta vừa sửa được lỗi kiến trúc hiện tại, vừa tránh COSA lại phình ra vì thêm một framework mới.

Các điểm kỹ thuật nền của tài liệu này bám theo ADK/Google Cloud hiện hành: ADK 2.0 hỗ trợ graph workflow; ADK hỗ trợ model bên ngoài và local; A2A nên dành cho ranh giới agent độc lập thay vì mọi sub-agent; OTel có thể dùng làm trace chuẩn; và evaluation có thể đưa vào CI/CD. ([ADK][3])

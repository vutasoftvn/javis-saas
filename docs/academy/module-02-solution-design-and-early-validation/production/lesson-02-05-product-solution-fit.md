# Lesson 2.5 — Evaluating Product-Solution Fit

**Target duration:** 3 × 28 seconds = approximately 84 seconds

| Video | Narrative job and composition | In-frame teaching slide | Prompt |
|---|---|---|---|
| 01 | Product-solution fit is early evidence that a solution helps a specific customer; it is not proof of scalable demand. Founder focus, no slide. | None | [64](prompts/64-lesson-02-05-video-01.md) |
| 02 | Examine evidence: meaningful outcome, repeated response, behavior, and segment fit. Founder + evidence model. | `Helpful for whom, how, and how often?` | [65](prompts/65-lesson-02-05-video-02.md) |
| 03 | Rate the evidence as strong, mixed, or weak; identify the next learning decision. Founder + decision slide. | `Strong / Mixed / Weak` | [66](prompts/66-lesson-02-05-video-03.md) |

**End action:** Rate current solution evidence and state the next test.

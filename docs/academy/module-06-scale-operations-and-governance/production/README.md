# Module 6 — Seedance Production Pack

Module 6 is the final Academy module: nine lessons, each assembled from three complete **28-second English** founder-led videos. Use the established pattern: founder hook with no slide; founder plus one conceptual model; founder plus action/decision slide. Join every three clips into an 84-second lesson with a soft dissolve or teal-light sweep.

Keep the same illustrated Vietnamese male founder, around 40, same wardrobe, English voice, 16:9 framing and COSA deep-navy studio. Add only a subtle **governance studio** atmosphere: ownership lines, trusted-data lights, approval boundary markers and warm desk light. Never produce detached presenter/slide assets, real COSA UI, dashboards, CRM, finance interfaces or charts.

Every prompt includes exact English voice script, native-level English male voice, quiet 78 BPM ambient music, restrained sound effects, English caption safe area and 0.75-second start/end handles. Use the [in-frame slide system](../../module-00-founder-foundations/production/slide-system.md) for the visual system.

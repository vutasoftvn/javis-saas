# Lesson 0.4 — From an Idea to a Project

**Target duration:** 3 × 28 seconds = approximately 84 seconds

**Learner promise:** The learner can turn an idea into a focused project instead of an unfocused task list.

| Video | Narrative job and composition | In-frame teaching slide | Prompt |
|---|---|---|---|
| 01 | Hook: an idea is optional; a project is a commitment to answer one meaningful question. Founder focus, no slide. | None | [10](prompts/10-lesson-00-04-video-01.md) |
| 02 | Model: explain the five elements of a project brief. Founder + example artifact. | `Customer + Problem + Hypothesis + Outcome` | [11](prompts/11-lesson-00-04-video-02.md) |
| 03 | Application: create a brief and three outcome-serving tasks. Founder + action slide. | `Project outcome → three actions` | [12](prompts/12-lesson-00-04-video-03.md) |

**End action:** Write a project brief: name, customer, problem, hypothesis, near-term outcome, and three first actions.

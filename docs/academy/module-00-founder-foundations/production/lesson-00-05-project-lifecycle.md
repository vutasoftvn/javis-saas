# Lesson 0.5 — The Project Lifecycle: Learn Before You Scale

**Target duration:** 3 × 28 seconds = approximately 84 seconds

**Learner promise:** The learner knows that every stage answers a different question and that evidence, not course completion, moves a project forward.

| Video | Narrative job and composition | In-frame teaching slide | Prompt |
|---|---|---|---|

| 03 | Application: review evidence before advancing; learning completion is not market evidence. Founder + decision slide. | `What must this project prove next?` | [15](prompts/15-lesson-00-05-video-03.md) |

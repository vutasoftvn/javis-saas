# Lesson 0.7 — OKRs for Early-Stage Founders

**Target duration:** 3 × 28 seconds = approximately 84 seconds

**Learner promise:** The learner can write a small, outcome-focused OKR and connect it to a Project and 12-week execution cycle.

| Video | Narrative job and composition | In-frame teaching slide | Prompt |
|---|---|---|---|
| 01 | Hook: being busy is not the same as progressing. Founder focus, no slide. | None | [19](prompts/19-lesson-00-07-video-01.md) |
| 02 | Model: clarify Objective, Key Result, and Task with an early-stage example. Founder + example artifact. | `Objective → Key Result → Task` | [20](prompts/20-lesson-00-07-video-02.md) |
| 03 | Application: connect project context, OKRs, 12-week rhythm, and weekly actions. Founder + action slide. | `Fewer, clearer, reviewed` | [21](prompts/21-lesson-00-07-video-03.md) |

**End action:** Create one Objective, no more than three Key Results, and one linked weekly task.

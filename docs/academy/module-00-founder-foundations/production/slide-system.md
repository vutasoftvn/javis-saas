# Module 0 — In-Frame Teaching Slide System

## Communication job

By the end of each short lesson, a first-time founder should understand one operating concept and know one action to take. The slide supports the founder's explanation; it never replaces the founder and is never a reproduction of the COSA product interface.

## COSA-derived visual tokens

| Role | Token | Use in the teaching screen |
|---|---|---|
| Deep canvas | `#070C18` | Main studio and slide background |
| Deep navy glow | `#0B1934` | Soft radial depth behind founder and slide |
| Surface navy | `#0D172A` | A small label or supporting area only |
| Primary teal | `#14B8A6` | Main concept, progress, action |
| Light teal | `#2DD4BF` | Highlight and connector |
| Sky blue | `#38BDF8` | Evidence and learning signal |
| Rose | `#F43F5E` | Risk or anti-pattern only |
| White | `#FFFFFF` | Takeaway title |
| Muted slate | `#94A3B8` | Supporting words |

Use a modern sans-serif font with strong English support. Keep the teaching screen deliberately sparse: one title, one visual structure, and no more than three support labels. Avoid dashboards, card grids, buttons, tabs, faux navigation, and dense product-like UI.

## Composite layout

| Situation | Composition | Motion |
|---|---|---|
| No slide | Founder is 65–70% of the frame, medium-close | Slow push-in; abstract studio depth shifts subtly |
| With slide | Founder on left 35–40%; screen on right 60–65% | Gentle teal light sweep introduces the screen; founder gestures once toward it |
| End action | Same split composition; action slide is visually clearest | Screen settles, founder looks back to camera, 0.75-second still handle |

All clips remain 16:9, use the same dark navy studio, and reserve the lower 18% for later English captions. Do not split the founder and slide into separate generated assets.

## Slide formats

### SL-01 — Takeaway claim

One large claim and a single supporting visual. Use for a definition or conclusion.

### SL-02 — Definition contrast

One concept with two or three concise contrasts. Use for “task versus decision” or “assumption versus evidence.”

### SL-03 — Operating loop

Three to five words connected by one simple line or cycle. Use only when sequence materially improves comprehension.

### SL-04 — Focus framework

One central question with up to three supporting elements. Use for founder ownership, project scope, or the 12-week cycle.

### SL-05 — Example artifact

One clean document-like composition that illustrates a project brief, research statement, weekly plan, or OKR. It is an educational illustration, not a COSA screenshot.

### SL-06 — Decision checkpoint

One question, two possible actions, and one clear criterion. Use for approvals, lifecycle progression, and review points.

### SL-07 — Learner action

One direct action prompt and a short fill-in-the-blank line. Use at the end of each lesson.

## Three-slide arc per lesson

Each lesson uses only two teaching screens because Video 01 intentionally has no slide. The visual arc is always **human tension → simple model or example → action**. The individual prompt files specify the exact slide title and elements.

# Lesson 1.1 — Problem Discovery Framework

**Target duration:** 3 × 28 seconds = approximately 84 seconds

| Video | Narrative job and composition | In-frame teaching slide | Prompt |
|---|---|---|---|
| 01 | Start with an observed customer problem, not a product idea. Founder focus, no slide. | None | [25](prompts/25-lesson-01-01-video-01.md) |
| 02 | Define a problem through customer, situation, painful job, workaround, and consequence. Founder + framework slide. | `Customer → Situation → Job → Consequence` | [26](prompts/26-lesson-01-01-video-02.md) |
| 03 | Separate observed facts from assumptions and write the first problem statement. Founder + action slide. | `I observed… / I assume…` | [27](prompts/27-lesson-01-01-video-03.md) |

**End action:** Write one customer–problem–context statement.

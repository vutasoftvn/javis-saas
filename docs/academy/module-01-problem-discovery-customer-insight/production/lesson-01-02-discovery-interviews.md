# Lesson 1.2 — Conducting Qualitative Discovery Interviews

**Target duration:** 3 × 28 seconds = approximately 84 seconds

| Video | Narrative job and composition | In-frame teaching slide | Prompt |
|---|---|---|---|
| 01 | An interview is for learning past behavior, not winning approval for an idea. Founder focus, no slide. | None | [28](prompts/28-lesson-01-02-video-01.md) |
| 02 | Use open questions about a recent situation, action, workaround, and consequence. Founder + question flow. | `Tell me about the last time…` | [29](prompts/29-lesson-01-02-video-02.md) |
| 03 | Capture quotes, stories, behavior, and follow-up questions in a consistent note. Founder + example note. | `Quote / Event / Workaround / Consequence` | [30](prompts/30-lesson-01-02-video-03.md) |

**End action:** Prepare five open-ended discovery questions.

# Zalo Workspace Tenancy and Snowflake Cutover Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Keep the Zalo personal QR connector for development while making every QR session and connection workspace-tenant-safe, and replace the JavisOS runtime's UUID identifiers with 64-bit Snowflake IDs serialized as strings.

**Architecture:** This is a development cutover, not an in-place production data migration. Replace the UUID Alembic history with one Snowflake baseline and recreate the local Postgres volume after exporting any disposable fixtures. QR login becomes a persisted, workspace-scoped job: the API creates/reads/cancels sessions, while `agent-worker` alone launches and supervises `zalo-agent-cli`.

**Tech Stack:** FastAPI, SQLAlchemy 2, Alembic, PostgreSQL 16, Flutter/Dart, Docker Compose, pytest, Flutter test.

## Global Constraints

- `frontend/` calls only `backend/app` versioned `/api/v1` endpoints; never call `javis/`, `backend/server`, port `8888`, or legacy WebSockets.
- Every resource access validates authenticated `workspace_id` and, where applicable, `brain_id`, on the server.
- Every entity PK and FK is `BIGINT` Snowflake; JSON/REST/Flutter identifiers are decimal strings.
- `backend/server/` and `javis/` remain reference-only and are not runtime dependencies.
- Zalo QR is development functionality, scoped to a workspace; it is not removed or proxied to legacy code.
- Background work runs only in `agent-worker`; `brain-api` never launches a polling loop or external connector process.
- This plan intentionally destroys the local development database. Do not apply it to an environment with data that must be retained.

## Cutover contract

### Identifier contract

```python
SnowflakeId = int  # PostgreSQL BIGINT, generated by generate_snowflake_id()

# Every JSON response
{"id": str(model.id)}

# Every FastAPI path/query/body ID
# Accept decimal string or integer, normalize with parse_snowflake_id(value) -> int.
```

No UUID is generated, parsed, stored, exposed, or embedded in a JSON relation after this cutover. `created_at` stays as a separate timestamp; it is not inferred from the Snowflake ID for business logic.

### Zalo QR contract

```text
POST /api/v1/connectors/zalo/sessions?workspace_id={snowflake-string}
  -> 201 {"id": "...", "state": "queued", "expires_at": "..."}

GET /api/v1/connectors/zalo/sessions/{session_id}?workspace_id={snowflake-string}
  -> {"id", "state", "qr_data_url", "connection_id", "error", "expires_at"}

POST /api/v1/connectors/zalo/sessions/{session_id}/cancel?workspace_id={snowflake-string}
  -> {"id": "...", "state": "cancelled"}
```

The API requires `get_current_workspace_member`. A session is visible or cancellable only when `session.workspace_id == member.workspace_id`; a mismatched ID returns 404. The worker claims queued sessions with `FOR UPDATE SKIP LOCKED`, starts the fixed `zalo-agent-cli@1.6.2` argv without shell interpolation, and writes state transitions to Postgres. QR data is retained only until terminal state or expiry, then cleared.

- [ ] **Step 3: Implement the shared conversion functions**

```python
# backend/app/core/id_types.py
from typing import Union

SnowflakeId = int

def parse_snowflake_id(value: Union[str, int]) -> SnowflakeId:
    if isinstance(value, bool):
        raise ValueError("Snowflake ID must be a positive decimal integer")
    text = str(value)
    if not text.isdecimal():
        raise ValueError("Snowflake ID must be a positive decimal integer")
    parsed = int(text)
    if not 0 < parsed < 2**63:
        raise ValueError("Snowflake ID is outside signed BIGINT range")
    return parsed

def serialize_id(value: SnowflakeId) -> str:
    return str(value)
```

- [ ] **Step 3: Implement service ownership and claim functions**

```python
def get_zalo_session_or_404(db: Session, session_id: int, workspace_id: int) -> ZaloQrSession:
    row = db.query(ZaloQrSession).filter(
        ZaloQrSession.id == session_id,
        ZaloQrSession.workspace_id == workspace_id,
    ).first()
    if row is None:
        raise HTTPException(status_code=404, detail="Zalo QR session not found")
    return row

def claim_next_zalo_qr_session(db: Session) -> ZaloQrSession | None:
    return db.query(ZaloQrSession).filter(ZaloQrSession.state == "queued").with_for_update(skip_locked=True).first()
```
